# プロジェクト仕様書：天敵ピンイン・リスニングトレーナー

このドキュメントは、中国語学習における「天敵ピンイン（聞き取りの罠）」に特化したリスニングトレーニング用Webアプリケーションの基本方針、要件定義、システム設計、およびデータ構造をまとめたものです。

---

## 1. 基本方針 (Project Philosophy)

中国語リスニングにおいて、日本人学習者が特につまずきやすい**「天敵ピンイン（音素のトラップ）」**を可視化し、集中してトレーニングすることで、効率的に聴取能力を向上させることを目指します。

- **視覚と聴覚 of 連動**: 天敵ピンインを色分けと下線で強調し、脳内の「音」と「文字（ピンイン）」の認識ズレを修正します。
- **無駄のない操作性**: 左手だけでほぼすべての制御（再生、速度変更、モード切り替え、ナビゲーション）を完結させ、テンポよく学習を繰り返せるUI/UXを提供します。
- **軽量・独立設計**: サーバ不要でブラウザ単体で動作する静的構成（HTML + CSS + JavaScript）を採用し、ローカルやGitHub Pages等で容易に公開・実行できるようにします。

## 2. 要件定義 (Requirements)

### 2.1. 3つの学習モード
1. **チャレンジモード (Challenge Mode / 回答前)**
   - 音声が再生されるが、漢字とピンインは伏せられた状態（`q-hidden`）。
   - スラッシュ `/` のみが表示され、文の区切り（チャンク数）だけが視覚的手がかりになります。
2. **アンサーモード (Answer Mode / 回答後)**
   - `Q`キー押下後に移行。すべての漢字とピンインが開示されます。
   - ピンイン部分には、罠の属性に応じた「カラー＆下線」が表示され、視覚的に警告します。
3. **要注意ピンイン爆撃モード (G-Bombardment Mode)**
   - `G`キー押下で起動。文に含まれる「天敵ピンイン単語」に順次フォーカスを当てます。
   - フォーカス時、該当単語のピンインは大きく（Giant）なり、角丸の結合カードとして強調表示されます。
   - **3連加速再生**: 該当単語のみを `0.7x` → `0.85x` → `1.0x` のスピードでテンポよく（250ms間隔）3回連続再生します。解説パネルには天敵の具体的な弱点が表示されます。

### 2.2. アシスト機能
- **お助けポーズ＆スラッシュ機能 (F-Mode)**
   - 音声が1チャンク（単語の塊）ごとに再生され、再生完了したチャンクの境界線に順次スラッシュ `/` が表示されます。
   - チャンク間に `800ms` のディレイを挟み、聞き手の理解スピードに配慮します。
- **未知語ヒント表示 (W-Mode)**
   - 指定したHSKレベル（1〜5級）以上の単語を「未知語」として抽出し、意味と難易度（HSK級）を提示します。
- **シャッフルモード (S-Mode)**
   - 問題をランダム順で出題します。デフォルトでON。ONのときは「S」キーのインジケータが緑色に点灯します。
- **可変速度ギア**
   - 等倍(1.0x)を中心に、`0.5x` 〜 `1.5x` の間で `0.1` 単位で調整可能（`1` `2` `3` キーで制御）。

### 2.3. 学習レベル選択 (Level Selector)
- サイドバーの「学習レベル（問題セット）」ドロップダウンで、難易度別の問題セットを切り替えられます。
- レベルは `HSK1 (入門)` → `HSK2 (初級)` → `HSK2-3 (橋渡し)` → `HSK3-4 (中級)` の4段階（詳細は[5. データ構造](#5-データ構造-data-フォルダ)を参照）。
- 切り替えると該当レベルの問題セットのみ再取得し、シャッフル順・現在の問題番号をリセットします（F/G/Wモード等の他機能はレベルに関わらず共通）。
- 選択したレベルは `localStorage` に保存され、次回起動時も同じレベルから再開します。

## 3. 操作仕様 (Key Bindings)

すべての主要機能をキーボードのキーにアサインし、左手デバイスやキーボード of ホームポジション付近で片手操作できるように設計されています。

| キー | アクション | 挙動詳細 |
| :--- | :--- | :--- |
| `Space` / `R` | **再生 / 再リピート** | 答え合わせ前は設定速度、答え合わせ後は等倍（1.0x）で文全体を再生。Gモード中は対象ワードのみ再生。 |
| `Q` | **答え合わせ (Reveal / G-Reset)** | チャレンジ（非表示）とアンサー（開示）の切り替え。Gモード実行中はGモードを解除して通常再生に戻る。 |
| `E` | **再チャレンジ (Re-Challenge)** | 答え合わせ後の状態をリセットし、再び答えを伏せたチャレンジ状態（初期状態）に戻す。 |
| `W` | **ヒント表示トグル (Word Hints)** | HSKフィルターに合致する単語の意味をサイドパネルに表示/非表示。 |
| `F` | **Fモード（スロー再生）** | 1チャンクずつハイライトしながら、800msの休止を挟んでスロー再生（答え合わせ後も有効）。 |
| `G` | **Gモード（ピンイン爆撃）** | 押すたびに文中の「天敵ピンイン」単語をループでフォーカス。加速3連打再生と弱点解説を表示。 |
| `S` | **シャッフルON/OFFトグル** | 問題順をランダムにするか、元の登録順にするかをトグル。 |
| `A` / `4` / `←` | **前の文へ** | 1つ前の問題に移動（シャッフルON時はシャッフル配列に沿う）。 |
| `D` / `5` / `→` | **次の文へ** | 1つ次の問題に移動。 |
| `1` | **速度ダウン** | 再生速度を `-0.1` 減速する（下限 0.5x）。 |
| `2` | **速度等倍化** | 再生速度を強制的に `1.0x` にリセットする。 |
| `3` | **速度アップ** | 再生速度を `+0.1` 加速する（上限 1.5x）。 |

## 4. デザインシステム & CSS構造

### 4.1. カラーパレット (Modern Sleek Dark Mode)
- 背景: 深い濃紺（`#0a0f1d` / `#121829`）
- テキスト: オフホワイト（`#f1f5f9`）
- フォーカス背景（座布団）: 温かみのあるイエロー系（`#fef08a` / 暗め `#fef9c3`）

### 4.2. 天敵ピンインの分類と色定義 (`data.js` 内のクラス)
中国語の音素のうち、日本人が混同しやすいものを5つのグループに分類し、異なるカラーコードと下線スタイルを適用しています。

| CSSクラス | 罠カテゴリ | カラーコード | デザイン特徴 | 代表的なピンイン例 |
| :--- | :--- | :--- | :--- | :--- |
| `.bad-an` | ローマ字読みの罠 (`-ian` / `-ui` / `-un`) | `#ff9f43` (オレンジ) | 2px 破線 | tiān, diàn, zuì, wèn |
| `.bad-e` | こもる『e』の罠 | `#ff6b6b` (レッド) | 2px 破線 | hē, rè, kě, zhè, me |
| `.bad-retro` | 巻き舌音の罠 (`zh` / `ch` / `sh` / `r`) | `#54a0ff` (ブルー) | 2px 破線 | zhǐ, chī, shì, rè, rén |
| `.bad-ing` | 鼻音終わりの罠 (`-ng`) | `#1dd1a1` (グリーン) | 2px 破線 | míng, péng, tīng, xīng |
| `.bad-front` | 前舌面音の罠 (`x-`) | `#c084fc` (パープル) | 2px 破線 | xǐ, xué, xīn, xiě |

### 4.3. 複合トラップの表現
「巻き舌」かつ「こもるe」である `rè` や、`shēng` のように複数の罠が1文字に重なる場合、CSSの優先順位と複合セレクタを駆使し、**「文字色は巻き舌（青）や前舌面（紫）」「下線の色は母音属性（オレンジ、赤、緑）」**となるようにデザインしています。
- 例: `.pinyin.bad-retro.bad-e` → 文字色: 青、下線: 赤

## 5. データ構造 (`data/` フォルダ)

問題データは `data/` フォルダ配下の複数のJSONファイルに外部化されており、`trainer.html` が起動時に `fetch()` で非同期に読み込みます（GitHub Pagesなど、HTTPサーバー経由で配信する必要があります。`file://` で直接開くとCORS制限により読み込みに失敗します）。

### 5.1. ファイル構成

| ファイル | 役割 |
| :--- | :--- |
| `data/levels.json` | レベル一覧のマニフェスト。`id` / `label` / `file` / `description` を持つ配列と `defaultLevelId`。サイドバーのレベル選択ドロップダウンはここから動的に生成される。 |
| `data/pinyin-master-db.json` | 天敵ピンインIDと解説文のマップ（全レベル共通、12種）。 |
| `data/hsk1.json` | HSK1語彙・基本文型のみの問題セット（40問）。 |
| `data/hsk2.json` | HSK2語彙中心の問題セット（40問）。 |
| `data/bridge.json` | HSK2→HSK3-4への橋渡しレベルの問題セット（40問）。 |
| `data/hsk3-4.json` | 従来からの問題セット。HSK3-4語彙が混在する中級レベル（40問）。 |

レベルを追加する場合は、新しい `data/xxx.json`（`{"studyData": [...]}`形式）を作成し、`data/levels.json` の `levels` 配列にエントリを追加するだけで、`trainer.html` 側の変更は不要です。

### 5.2. `studyData` の各エントリの形式

各レベルファイルの `studyData` 配列の要素は、以下の形式を満たす必要があります。

```json
{
  "full_sentence": "他学了两年中文，说得非常好。",
  "japanese_translation": "彼は2年間中国語を学んで、とても上手に話せます。",
  "tip": "学(xué)の前舌音、年(nián)の『イェン』省略、中(zhōng)の巻き舌＋鼻音、说(shuō)と得(de)の発音のギャップが難所です。",

  "html_content": "<div class=\"chunk-box\" data-chunk-index=\"0\">\n    <div class=\"char-box\"><span class=\"pinyin\">tā</span><span class=\"hanzi\">他</span></div>\n    <div class=\"char-box\"><span class=\"pinyin bad-front\">xué</span><span class=\"hanzi\">学</span></div>\n    ...\n  </div>",

  "chunks": [
    {
      "text": "他学了两年",
      "words": [
        {"word": "两年", "level": 2, "meaning": "2年間"},
        {"word": "学", "level": 1, "meaning": "学ぶ"}
      ]
    }
  ],

  "vulnerable_targets": [
    {
      "text": "学",
      "enemy_id": "ROM-ü,VOW-xi",
      "html": "<div class=\"char-box\"><span class=\"pinyin bad-front\">xué</span><span class=\"hanzi\">学</span></div>"
    }
  ]
}
```

`html_content` と `vulnerable_targets[].html` は（JSONの制約上テンプレートリテラルが使えないため）HTML文字列として `\n` や `\"` をエスケープした通常の文字列で保持します。

## 6. 今後の展望・機能拡張案 (Future Roadmap)

1. **学習進捗と苦手単語の永続化 (LocalStorage)**
   - 各問題の「正誤履歴（理解度: 完璧/あいまい/不可）」や「Gモード実行回数」をローカルに保存し、苦手な問題だけを重点的にシャッフル出題するフィルタ機能。
2. **解説カードの音声読み上げ (TTS Integration)**
   - Gモード移行時、解説パネルに表示される「天敵の解説テキスト」を日本語音声で自動的に読み上げる機能（視線を画面下に落とさずに耳だけでトレーニングを完結させるため）。
3. **ユーザー独自の文章インポート機能**
   - 外部からテキストとピンインのペアを入力すると、自動で「天敵ピンイン」を検出してデータオブジェクトを生成する簡易パーサー機能。
