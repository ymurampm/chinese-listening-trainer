💡 語彙・文法解説

会話文の中のハイライト語彙（例：有点儿、一边...一边...）や単語チップをタップすると解説が表示されます。

⌨️ キーボードショートカット一覧

キー 機能
J / K次のセリフ / 前のセリフへ移動して再生
gg / G会話の【先頭（1行目）】 / 【末尾（最終行）】へジャンプ
P / Space選択中のセリフを再生 / 一時停止 (Shift+P で全文再生)
R / .現在のセリフをリピート（例: 3r で3回自動連続再生！）

N / MNで語彙解説スイッチ / Mで単語発音
Y / T / ZYでピンイン切替 / T・Zで日本語訳表示切替
< / > (または [/])再生速度の減速 / 加速
S / Esc音声再生・リピートをストップ
1 / 2 / 3学習モード切替（1:リスニング 2:ロールプレイ 3:クイズ）
